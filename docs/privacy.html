Политика конфиденциальности

Дата: 16 ноября 2026 г.

excel.fishki autopost — частный инструмент для публикации роликов проекта excel.fishki на собственных аккаунтах владельца проекта.

Какие данные используются

  • OAuth-токены доступа к YouTube-каналу и Instagram-аккаунту владельца. Они хранятся в зашифрованных секретах GitHub Actions и используются только для загрузки роликов.
  • Ролики, обложки и подписи, подготовленные владельцем.

Чего инструмент не делает

  • Не собирает, не хранит и не передаёт данные других пользователей YouTube или Instagram.
  • Не продаёт и не передаёт данные третьим лицам.
  • Не использует данные для рекламы.

Сервисы Google

Использование и передача данных, полученных через API Google, соответствуют Google API Services User Data Policy, включая требования Limited Use. Инструмент использует YouTube API Services; применяются Условия использования YouTube и Политика конфиденциальности Google. Отозвать доступ можно на странице настроек безопасности Google.

Удаление данных

Владелец может в любой момент отозвать доступ в настройках Google и Instagram и удалить секреты из GitHub — после этого инструмент не хранит никаких данных.
